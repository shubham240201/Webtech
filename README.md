# Binge Guide

Binge Guide is a movie and TV show discovery platform built using React and Firebase.

## Features

* Search Movies and TV Shows
* Trending Content Dashboard
* User Authentication
* Responsive UI
* Firebase Integration

## Technologies Used

* React.js
* Firebase
* Redux Toolkit
* Material UI
* Tailwind CSS
