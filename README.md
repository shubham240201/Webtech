## 📌 About

**Binge Guide** is a fully responsive movie and TV show discovery application that lets users explore, search, and save their favourite content — powered by the TMDB API and backed by Firebase for real-time user data.

---

## ✨ Features

- 🔍 **Search** — Find any movie or TV show instantly
- 🎬 **Browse 1,000+ titles** — Movies, TV shows, trending, top-rated
- ❤️ **Watchlist & Favourites** — Save content to personal lists (Firebase persisted)
- 🔐 **User Authentication** — Sign up / Login via Firebase Auth
- 📱 **Fully Responsive** — Mobile, tablet, and desktop ready
- ⚡ **Optimized Performance** — RTK Query for efficient API caching

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React 18 | Frontend UI library |
| Redux Toolkit | Global state management |
| RTK Query | API data fetching & caching |
| Firebase Auth | User authentication |
| Firebase Firestore | Watchlist & favourites storage |
| Firebase Hosting | Deployment |
| TMDB API | Movie & TV show data |
| Tailwind CSS | Styling |
| PostCSS | CSS processing |

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/shubham240201/Binge-Guide.git
cd Binge-Guide

# 2. Install dependencies
npm install

# 3. Create .env file and add your keys
REACT_APP_TMDB_API_KEY=your_tmdb_api_key
REACT_APP_FIREBASE_API_KEY=your_firebase_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
REACT_APP_FIREBASE_PROJECT_ID=your_project_id

# 4. Start development server
npm start

# 5. Build for production
npm run build
```
